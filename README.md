# otahstudio-midia

Mídia pública e memória da esteira de conteúdo do @otaviohenriqve.

- `docs/ESTEIRA.md`: o manual que as tarefas automáticas seguem.
- `data/registro.json`: todas as peças criadas, com notas, assinatura de layout e status.
- `data/performance/`: foto diária do desempenho de cada post (30 dias por post).
- `data/aprendizados.md`: o que funciona e o que não funciona, reescrito toda noite.
- `posts/AAAA-MM-DD-tema/`: imagens e legenda de cada post (links públicos usados no agendamento).
- `assets/fotos/`: coloque aqui fotos suas para os carrosséis usarem.
